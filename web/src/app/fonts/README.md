# Fonts

Bundled so the site builds and runs with no network (demo safety). Latin subsets only: every
question in the packs is Latin text outside its LaTeX, and KaTeX ships its own maths fonts.

| File | Font | Licence |
|---|---|---|
| `inter-latin.woff2` (variable, 400-600 used) | [Inter](https://github.com/rsms/inter) | [OFL-inter.txt](OFL-inter.txt) |
| `space-grotesk-latin.woff2` (variable, 500-700 used) | [Space Grotesk](https://github.com/floriankarsten/space-grotesk) | [OFL-spacegrotesk.txt](OFL-spacegrotesk.txt) |
| `ibm-plex-mono-400-latin.woff2`, `ibm-plex-mono-500-latin.woff2` | [IBM Plex Mono](https://github.com/IBM/plex) | [OFL-ibmplexmono.txt](OFL-ibmplexmono.txt) |
| `silkscreen-700-latin.woff2` | [Silkscreen](https://github.com/googlefonts/silkscreen) | [OFL-silkscreen.txt](OFL-silkscreen.txt) |

All four are under the SIL Open Font License 1.1. The files are the Latin subsets served by Google
Fonts, unmodified apart from the file names.
